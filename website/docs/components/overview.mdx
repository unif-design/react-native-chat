11 个可独立使用的聊天组件，共用 Unif Design 的主题、基础控件和字体。按需要选择组件，也可以组合完整聊天页。

<ComponentCatalog />

先阅读[安装与宿主](../getting-started.mdx)，或直接查看[主聊天组合](../composition/main-chat.mdx)。

组件只负责展示与用户交互。应用持有消息、草稿、附件、请求状态与业务事实，并在事件中处理后续动作。
