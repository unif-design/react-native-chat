## 用法

```tsx
<Message name="智能助手" text="你好，今天想聊些什么？" />
<Message placement="end" text="帮我整理一份提纲。" />
<Message
  format="markdown"
  text="**整理思路**：先确认主题，再补充资料。"
  onLinkPress={(url) => openLink(url)}
/>
```

## 行为与接入

正文使用 `text` 或 `children`，两种形式互斥。`format="markdown"` 使用真实 Markdown 渲染器；链接点击由 `onLinkPress` 交出。自定义卡片可以包含按钮等交互内容。

Markdown 图片使用原始资源地址，位图保持比例，SVG 沿 `react-native-marked` 的矢量图片能力加载。当前渲染器按完整地址的 `.svg` 后缀识别 SVG，带查询参数或片段的 SVG 地址尚不自动识别。图片链接也只通过 `onLinkPress` 交付，未提供回调时保持静态。

默认 `placement="start"`、`surface="bubble"`、`status="idle"`，`fullWidth` 默认关闭。身份、消息状态和附加区域只展示调用方提供的信息。

`actions` 表示消息操作。正文中的链接、按钮等交互区域独立交付事件；消息外壳支持 `onPress` 和 `onLongPress`。

默认气泡使用 `radius['2xl']`，水平 `space[5]`、垂直 `space[4]` 留白，最大占消息行宽的 78%。外发文字采用品牌色底与 `onPrimary` 文字；卡片使用 `fullWidth` 和 `surface="plain"`，附件自行提供中性表面。普通正文和 Markdown 正文采用 `type.sm`，字体系数只应用一次。

有 `icon` 的消息操作显示独立图标按钮，`label` 保留为中文可访问名称；没有图标的动作显示文字按钮。

空的 `pending`／`streaming` 用三点显示等待，`statusText` 可提供真实阶段文案；正文、header、footer 或自定义内容到达后撤下等待。三点遵守减少动态效果，卸载停止动画；它不生成身份、推理内容或业务进度。

`failed` 保留消息并以 0.7 透明度表达失败，不额外绘制红边。调用方提供 `failureAction` 时，气泡旁显示错误图标按钮（外发消息在左）；它沿用 `ChatAction` 的中文 label、disabled、loading 和 onPress。只有实际失败时才呈现该操作，未提供不生成重试。
