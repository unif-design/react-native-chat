
## 行为与接入

默认标题为“参考来源”。`label`、顺序、来源关系、标题与说明都由消费者提供；点击事件返回原项。

禁用项不交付点击事件。组件不查询来源、不核实信息，也不自动打开链接；正文里的独立标记可使用 [Citation](./citation.mdx)。
