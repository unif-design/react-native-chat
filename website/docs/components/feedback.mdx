## 用法

```tsx
<Feedback
  tone="warning"
  title="资料尚未完整"
  message="补充剩余信息后再继续。"
  action={{ id: 'edit', label: '补充信息', onPress: openEditor }}
/>
```

## 行为与接入

`tone` 默认 `info`，还支持 `success`、`warning` 与 `error`。`message` 为必要说明，标题和操作可选。

组件只显示给定内容，不从错误文字判断是否能重试。`action` 使用共同的 ChatAction；未传操作时不会增加按钮，也不会自动重发请求。
