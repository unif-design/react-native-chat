## 用法

```tsx
<Attachments
  items={attachments}
  layout="preview"
  onPreview={(item) => openPreview(item)}
  onRemove={(item) => removeAttachment(item.id)}
/>
```

## 行为与接入

`items` 使用稳定的 `id`，预览和移除事件返回原项。没有条目时不占位；未提供名称显示“未命名附件”。

`layout` 默认 `grid`，也支持 `compact`、`mixed`、`carousel` 、`list` 与 `preview`。`compact` 在仅有移除操作时将入口保留在缩略格右上角；同时支持整图预览或中央重试时，保留独立的44点移除操作槽，避免点图片中心误删，此时占宽超过图片框。预览、移除和重试继续交付各自原项。图片与进度复用 Design。`status` 默认 `idle`，`loadingVisual` 默认 `center`，也支持仅显示文字的 `caption`；`showProgressLabel` 默认关闭。

`preview` 用于输入区的大图横向预览，图片为 `r(120)`、圆角 `r(20)`，删除按钮保留独立44点入口并位于图片右上角；图片中心继续用于预览或重试。其余格状布局的图片使用 `r(76)` 的缩略图，不额外显示图片文件名；可预览时点击整图。`mixed` 中的文档使用 `r(64)` 的整行和 `r(36)` 的缩略图，保留名称与元信息，点击名称或缩略图交付同一个预览事件。移除目标独立于预览，中心上传/处理状态和失败重试也保留各自的命中范围。

只有 `uploading` 且比例是 `[0, 1]` 内的有限数时显示进度，未知比例使用忙碌指示；`processing` 不沿用旧上传比例。图片加载失败仅显示缩略图占位，不会改写宿主附件的处理状态。

进度、可移除状态与附件集合由应用提供。组件不读取本地文件、不上传、不保存文件，也不在点击移除后自行删项。
