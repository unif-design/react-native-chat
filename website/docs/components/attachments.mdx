## 用法

```tsx
<Attachments
  items={attachments}
  layout="preview"
  onPreview={(item) => openPreview(item)}
  onRemove={(item) => removeAttachment(item.id)}
/>
```

## 行为与接入

`items` 使用稳定的 `id`，预览和移除事件返回原项。没有条目时不占位；未提供名称显示“未命名附件”。

`layout` 默认 `grid`，也支持 `compact`、`mixed`、`carousel` 、`list` 与 `preview`。`compact` 在仅有移除操作时将入口保留在缩略格右上角；同时支持整图预览或中央重试时，保留独立的44点移除操作槽，避免点图片中心误删，此时占宽超过图片框。预览、移除和重试继续交付各自原项。图片与进度复用 Design。图片上传的中央标签与 caption 仅显示取整后的数字（如 `42`），圆环和读屏仍表达完整百分比；文件标签保留 `%`。`status` 默认 `idle`，`loadingVisual` 默认 `center`，也支持仅显示文字的 `caption`；`showProgressLabel` 默认关闭。

`preview` 用于输入区的横向预览，图片与文件卡片均为 `r(96) × r(96)`、圆角 `r(20)`，删除按钮保留独立44点入口并位于图片右上角；图片中心继续用于预览或重试。其余格状布局的图片使用 `r(76)` 的缩略图，不额外显示图片文件名；可预览时点击整图。`mixed` 中的文档使用 `r(64)` 的整行和 `r(36)` 的缩略图，保留名称与元信息，点击名称或缩略图交付同一个预览事件。移除目标独立于预览，中心上传/处理状态和失败重试也保留各自的命中范围。

图片上的普通移除圆圈、中央上传／处理／重试圆层复用 Design 暗色 `GlassLayer` 与白色前景，平台降级由 Design 处理。小移除圆圈只裁切视觉区，中央圆层保留大字号百分比的显示空间；44点触达区保持独立，失败状态继续使用红色移除圆圈和图片描边。附件继续操作使用共享 `Button` 的 secondary 玻璃表面。

只有 `uploading` 且比例是 `[0, 1]` 内的有限数时显示进度，未知比例使用忙碌指示；`processing` 不沿用旧上传比例。图片加载失败仅显示缩略图占位，不会改写宿主附件的处理状态。

失败附件在 `loadingVisual="center"` 时将单一 `id: 'retry'` 动作显示在图片中心；`caption` 将失败说明与操作保留在图片下方，可预览时直接点击整图，不额外显示眼睛按钮。预览、重试和移除分别交付原事件；`icon` 只控制图形，不参与动作类型判断。

进度、可移除状态与附件集合由应用提供。组件不读取本地文件、不上传、不保存文件，也不在点击移除后自行删项。
