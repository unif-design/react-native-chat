## 用法

```tsx
<Process
  title="资料整理"
  steps={steps}
  expandedIds={expandedIds}
  onExpandedChange={setExpandedIds}
/>
```

## 行为与接入

每个步骤使用稳定 `id` 并显式提供 `status`。标题、说明、`elapsedMs` 和 `details` 均来自调用方；耗时不会在组件内自行计时。

展开可使用受控的 `expandedIds` + `onExpandedChange`，也可通过 `defaultExpandedIds` 设置一次性初始值。默认收起；没有详情的项不提供展开操作。

过程组件不执行任务、不解析工具协议，也不根据步骤名称推断业务行为。多组过程由页面组合多个 Process。
