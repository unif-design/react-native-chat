## 状态与事件

消息集合、草稿和附件由页面持有。发送事件将原始文字交给页面，再由页面决定追加消息与清空草稿。示例只更新本地状态，不连接 Agent 或业务接口。

## 宿主责任

页面提供有界高度、键盘避让和安全区。MessageList 管理列表位置，Composer 管理输入区展示；Chat 负责组合布局。
