## 独立草稿

抽屉由所属场景持有草稿、附件与处理状态。它不需要创建完整聊天历史；如果多个入口共享业务草稿，由应用明确交接。

## 键盘与手势

示例的 Modal 内提供手势根，键盘和安全区由抽屉宿主统一处理。浏览器可以验证展开、关闭和事件交接；软键盘与原生手势需在 iOS、Android 设备上验收。
